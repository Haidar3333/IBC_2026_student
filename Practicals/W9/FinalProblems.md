# Week 9: R II Scripting

## File Processing
Script: `matrix_stats.R`  
Output: `MatrixStats.tsv` (file, rows, columns, proportion of 1s and 0s).

## Leaf Areas
Script: `leaf_area.R`  
Output: `LeafAreaResults.csv` (leaf areas at t1 and t2 and growth per plant).

**Average growth:** Printed by `leaf_area.R` after running it with the class photos. The photos were not provided, so the number cannot be calculated here.

## Run
